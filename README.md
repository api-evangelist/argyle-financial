# Argyle (argyle-financial)

Argyle is a consumer-permissioned employment and income data platform. The REST API and Link SDK let lenders, mortgage originators, background-check firms, gig marketplaces, and government benefits programs verify a worker's identity, employment, income, paystubs, deposits, shifts, gigs, and ratings directly from the source payroll, gig, and banking systems. Verification workflows ship as a single API surface that can be embedded through hosted Link, web/iOS/Android/React Native/Flutter SDKs, or driven entirely server side. Argyle covers approximately 90% of the U.S. workforce and is used by partners including Checkr, NFM Lending, Regional Finance, and LMCU, with loan-origination integrations into Encompass, nCino, Empower, and Byte.

### Argyle Users API

Manages the lifecycle of Argyle users — the consumers who connect their payroll, gig, or banking accounts. Supports creation, retrieval, update, deletion, and listing of users, plus generation of short-lived user tokens for initializing the Link SDK in browser, mobile, or hosted flows.

- **Human URL:** [https://docs.argyle.com/api-reference/users](https://docs.argyle.com/api-reference/users)

### Argyle Accounts API

The Accounts API lets you retrieve, list, disable updates for, or delete those connections — and is the anchor point for downstream data sets such as identities, paystubs, employments, shifts, gigs, and bank accounts.

- **Human URL:** [https://docs.argyle.com/api-reference/accounts](https://docs.argyle.com/api-reference/accounts)
